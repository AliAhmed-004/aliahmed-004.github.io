The short version

My coding journey started with a simple Java app that didn't explode on launch (a win, if you ask me). I quickly found my true calling in Flutter: sleek, cross-platform apps with my sanity mostly intact.

I'm proficient in Dart, Python, C++ and Java. Basically, if it's got syntax, I'm interested. I love solving complex problems and building apps that just work, preferably without a network connection.

When I'm not wrestling with bugs, I'm battling it out in video games or discovering new cooking disasters in the kitchen. Let's build something awesome together.
